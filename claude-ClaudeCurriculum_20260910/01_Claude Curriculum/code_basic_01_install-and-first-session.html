Claude Code · 초급 · 모듈 01

설치와 첫 세션

Claude Code를 설치해 로그인하고, 안전한 샌드박스 프로젝트에서 세션을 시작해 코드베이스를 파악하는 질문을 던져 봅니다. 이 모듈에서는 파일을 전혀 수정하지 않습니다.

2. 학습 목표

설명

이 모듈을 마치면 다음을 할 수 있습니다.

  1. 자신의 OS에 Claude Code를 설치하고 버전을 확인할 수 있다.
  2. 로그인한 뒤 프로젝트 디렉터리에서 세션을 시작하고 종료할 수 있다.
  3. 탐색 질문으로 코드베이스의 목적과 구조를 파악할 수 있다.

3. 사전 준비

설명

3-1. 준비물

항목내용
필요 플랜Pro·Max·Team·Enterprise 중 하나. Free 계정으로는 이 코스를 진행할 수 없습니다. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인)
설치이 모듈에서 진행합니다. 사내 표준은 네이티브 설치입니다.
지원 OSmacOS 13.0 이상 / Windows 10(빌드 1809 이상)·Windows Server 2019 이상 / Ubuntu 20.04 이상 / Debian 10 이상 / Alpine Linux 3.19 이상. 4GB 이상 RAM 권장, 인터넷 연결 필수. (출처: code.claude.com/docs/en/setup, 2026-08-26 확인)
터미널macOS Terminal, Linux 셸, 또는 Windows의 WSL·Git Bash. 터미널이 처음이라면 공식 터미널 가이드를 먼저 보세요.
사전 지식기본적인 셸 명령(cd, ls)과 git 사용 경험. 이 코스는 개발자 대상입니다.
실습 대상샌드박스 프로젝트. 실습 4단계에서 새로 만듭니다. 사내 실제 코드는 쓰지 않습니다(3-3 참조).
예상 사용량탐색 질문 3회. 파일을 수정하지 않으므로 소모량이 적습니다.

3-2. 이 문서의 표기 방식

Claude Code는 터미널에서 동작하는 CLI라 화면이 한국어로 제공되지 않습니다. 커맨드·플래그·터미널 출력은 영문 원문 그대로 싣고, 설명만 한국어로 씁니다.

표기의미
claude --version터미널에 입력하는 셸 명령
/helpClaude Code 세션 안에서 입력하는 세션 커맨드
따옴표 없는 문장세션 안에서 Claude에게 자연어로 보내는 프롬프트
셸 명령의 기준 환경

이 문서의 셸 명령은 macOS·Linux·WSL 기준입니다. Windows에서 차이가 있으면 그 자리에 함께 적었습니다. Windows에서 네이티브로 쓰는 경우 Git for Windows 설치를 권장합니다. 설치돼 있지 않으면 Claude Code가 Bash 도구 대신 PowerShell을 셸 도구로 사용합니다. WSL 환경은 Git for Windows가 필요 없습니다. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인)

3-3. 반드시 샌드박스에서 실습합니다

사내 실제 코드로 실습하지 마세요

Claude Code는 파일을 직접 고치고 명령을 실행하는 도구입니다. 게다가 설치 후 첫 세션에서는 변경할 때마다 승인을 묻지만, 그다음 세션부터는 Pro·Max·Team 플랜에서 "auto mode"가 기본 권한 모드가 됩니다. auto mode에서는 사람이 아니라 별도의 분류기(classifier)가 각 동작을 대신 검토하며, 대부분의 파일 수정과 명령 실행이 승인 없이 진행됩니다. (Enterprise 플랜은 계속 승인을 묻는 기본 모드를 유지합니다.) 자세한 내용은 모듈 02에서 다룹니다. 초급 학습자가 실제 업무 저장소에서 시작하면 의도치 않은 변경이 생길 수 있습니다. (출처: code.claude.com/docs/en/permission-modes, 2026-08-26 확인)

그래서 이 코스는 4단계에서 새로 만드는 샌드박스 프로젝트에서만 실습합니다. 모듈 02~04도 같은 샌드박스를 이어서 씁니다. 이 모듈 자체는 읽기 전용 질문만 하므로 파일이 바뀌지 않습니다. (여기서 "샌드박스"는 안전하게 연습할 별도 폴더를 뜻하는 일반적 표현입니다. Claude Code에는 Bash 명령 실행 자체를 격리하는 별도 기능인 Sandbox도 있는데, 이 폴더와는 다른 개념이며 이후 모듈에서 다룹니다.)

4. 핵심 개념

설명

4-1. 결론부터

Claude Code는 코드베이스를 읽고, 파일을 고치고, 명령을 실행하는 터미널 기반 에이전틱 도구입니다. 첫 모듈에서는 그중 "읽기"만 시켜 봅니다. 도구가 내 프로젝트를 어떻게 이해하는지 먼저 확인한 뒤에 쓰기를 맡기는 순서가 안전합니다.

4-2. 어디서 쓸 수 있나

Claude Code는 여러 환경에서 동작합니다. 터미널 CLI, VS Code·JetBrains 같은 IDE, 데스크톱 앱, 웹(claude.ai/code — 데스크톱 브라우저뿐 아니라 iOS·Android용 Claude 앱에서도 접속할 수 있습니다), Slack, 그리고 GitHub Actions·GitLab 같은 CI/CD입니다. (출처: code.claude.com/docs/en/overview, 2026-08-26 확인)

이 코스는 터미널 CLI를 기준으로 합니다. 설정 파일과 CLAUDE.md가 모든 환경에서 공통으로 쓰이므로, 터미널에서 배운 내용이 나머지 환경에도 그대로 적용됩니다.

4-3. 설치 방식과 자동 업데이트

방식대상자동 업데이트
네이티브 설치macOS·Linux·WSL·Windows됨 — 백그라운드에서 최신 버전 유지
HomebrewmacOS·Linux안 됨 — brew upgrade 필요
WinGetWindows안 됨 — winget upgrade 필요

사내 표준을 네이티브 설치로 정한 이유가 여기 있습니다. 학습자마다 버전이 달라지면 화면과 동작이 어긋나 재현성이 떨어집니다. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인)

4-4. 컨텍스트를 직접 넣지 않아도 됩니다

웹 Claude에서는 파일을 직접 업로드해야 했지만, Claude Code는 필요한 파일을 스스로 찾아 읽습니다. 어떤 파일을 봐야 하는지 지정하지 않아도 됩니다. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인) 이 모듈의 탐색 질문이 짧은 것도 그래서입니다.

4-5. 셸 명령과 세션 커맨드는 다릅니다

구분어디서 입력예
셸 명령터미널 (Claude Code 시작 전)claude, claude --version, claude -c
세션 커맨드Claude Code 실행 중/help, /clear, /exit

이 모듈에서는 claude, claude --version(셸)과 /help, /exit(세션)만 씁니다. 나머지는 모듈 03에서 다룹니다. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인)

5. 단계별 실습

실습

만들 결과물: 동작하는 Claude Code 설치본 + 샌드박스 프로젝트 + 프로젝트 구조를 설명한 응답 1건.

  1. 요금제를 확인합니다

    claude.ai에 로그인해 자신의 플랜이 Pro·Max·Team·Enterprise 중 하나인지 확인합니다. Free 플랜이라면 여기서 멈추고 관리자에게 문의하세요. 이후 단계를 진행할 수 없습니다.

  2. Claude Code를 설치합니다

    터미널을 열고 자신의 환경에 맞는 명령을 한 줄만 실행합니다.

    macOS · Linux · WSL (기준 환경)
    curl -fsSL https://claude.ai/install.sh | bash
    Windows PowerShell
    irm https://claude.ai/install.ps1 | iex
    Windows CMD
    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
    PowerShell인지 CMD인지 구분하는 법

    프롬프트가 PS C:\로 시작하면 PowerShell, PS 없이 C:\면 CMD입니다. 잘못 고르면 이런 오류가 납니다. CMD 명령을 PowerShell에서 실행하면 The token '&&' is not a valid statement separator, PowerShell 명령을 CMD에서 실행하면 'irm' is not recognized as an internal or external command. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인)

  3. 설치를 검증하고 버전을 기록합니다

    터미널에서 아래를 실행합니다.

    셸 명령
    claude --version

    버전 번호 뒤에 (Claude Code)가 출력되면 설치에 성공한 것입니다. 이 출력을 메모해 두세요. 나중에 문서와 동작이 다를 때 버전 차이인지 확인하는 근거가 됩니다.

    여기까지 — Claude Code 설치
    • claude --version이 버전과 (Claude Code)를 출력한다
    • 그 버전 문자열을 어딘가에 적어 두었다

    출력이 안 나오면 다음 단계로 가지 말고 7번 절의 command not found 항목부터 확인하세요. 설치가 안 된 상태로는 이후 단계가 전부 막힙니다.

  4. 샌드박스 프로젝트를 만듭니다

    아래 스크립트 전체를 복사해 터미널에 붙여 넣고 한 번에 실행합니다. 홈 디렉터리에 claude-code-sandbox 폴더가 생기고, git 저장소로 초기화되며 첫 커밋까지 만들어집니다. 스크립트 전문과 설명은 6번 절에 있습니다.

    Windows에서 실행하는 경우

    이 스크립트는 bash 문법입니다. Git Bash 또는 WSL 터미널에서 실행하세요. PowerShell·CMD에서는 동작하지 않습니다.

  5. 샌드박스가 정상 동작하는지 확인합니다

    Claude Code를 켜기 전에 프로젝트 자체가 잘 돌아가는지 먼저 봅니다.

    셸 명령
    cd ~/claude-code-sandbox
python3 app.py inventory.csv
    예상 출력
    [재고 부족] A4 용지 - 현재 4개
[재고 부족] USB 케이블 - 현재 7개

    이 두 줄이 그대로 나오면 준비 완료입니다.

  6. 샌드박스 디렉터리에서 Claude Code를 시작합니다

    앞 단계에서 이미 cd로 이동했다면 아래 한 줄만 실행합니다.

    셸 명령
    claude

    반드시 프로젝트 디렉터리 안에서 실행해야 합니다. Claude Code는 실행한 위치를 작업 디렉터리로 삼기 때문입니다.

  7. 로그인합니다

    첫 실행이면 로그인하라는 안내가 나옵니다. 화면의 안내를 따라 브라우저에서 인증을 마칩니다. 한 번 로그인하면 자격 증명이 저장되어 다시 로그인할 필요가 없습니다.

    로그인 대신 API 키 승인 화면이 뜬다면

    ANTHROPIC_API_KEY 환경 변수가 설정된 상태입니다. 이 경우 Claude Code는 로그인 절차를 건너뛰고 그 키를 쓸지 승인만 요청합니다. 사내 구독 계정으로 실습하려면 승인을 거절하고, 터미널에서 해당 환경 변수를 해제한 뒤 다시 시작하세요. (출처: code.claude.com/docs/en/quickstart, 2026-08-26 확인)

    [캡처 C-01]
    화면
    브라우저 인증 화면
    진입 경로
    터미널에서 claude 실행 → 안내에 따라 브라우저 열림
    캡처 범위
    브라우저 창의 인증 영역
    강조 표시
    승인 버튼(빨간 테두리)
    캡션
    첫 실행 시 브라우저에서 계정 인증을 마친다. 이후에는 다시 로그인하지 않는다.
    근사 목업 실제 화면과 다를 수 있는 근사 목업입니다. 이 문서를 제작한 환경은 이미 인증이 끝난 CLI 세션이며, 로그아웃하고 인증을 처음부터 다시 밟으면 이후 실습 재현이 막히기 때문에 실제 브라우저 화면 대신 재현했습니다. 주소창의 도메인·경로는 실제 로그인 시도에서 뜨는 URL을 그대로 옮겼습니다.
    claude.com/cai/oauth/authorize?client_id=…&redirect_uri=platform.claude.com%2Foauth%2Fcode%2Fcallback&scope=…

    Claude Code 로그인

    Claude Code가 아래 계정으로 로그인하려고 합니다.

    you@company.com

    계속하면 Claude Code가 이 계정의 구독으로 세션을 시작합니다.

    Authorize Cancel
  8. 환영 화면에서 세 가지를 확인합니다

    세션이 열리면 프롬프트 위에 버전, 현재 모델, 작업 디렉터리가 표시됩니다. 작업 디렉터리가 claude-code-sandbox인지 반드시 확인하세요. 다른 경로라면 /exit으로 나가서 6단계부터 다시 합니다.

    [캡처 C-02]
    화면
    Claude Code 환영 화면
    진입 경로
    샌드박스 디렉터리에서 claude 실행 직후
    캡처 범위
    터미널 창 전체(프롬프트 위 정보 줄이 모두 보이게)
    강조 표시
    버전·모델·작업 디렉터리 세 항목(각각 빨간 테두리)
    캡션
    세션 시작 화면. 작업 디렉터리가 실습용 샌드박스인지 여기서 확인한다.
    근사 목업 실제 화면과 다를 수 있는 근사 목업입니다. 이 화면은 로그인을 마쳐야 나타나는데, 이 문서를 제작한 클라우드 환경에는 연결된 브라우저가 없어 C-01의 로그인을 끝까지 진행하지 못했습니다. 아래 버전·모델 문자열은 이 환경에 설치된 CLI에서 claude --version과 /context로 실제 확인한 값입니다.
     Terminal — claude
    $ claude

   /help for help, /status for your current setup

 > Try "what does this project do?"
  9. /help로 커맨드 목록을 봅니다

    세션 안에서 아래를 입력합니다. 지금 단계에서는 목록만 훑어보면 됩니다. 각 커맨드는 이후 모듈에서 하나씩 다룹니다.

    세션 커맨드
    /help
    [캡처 C-03]
    화면
    /help 실행 결과
    진입 경로
    세션 안에서 /help 입력
    캡처 범위
    커맨드 목록이 보이는 범위
    강조 표시
    없음

실행할 스크립트 전문 — 전체를 복사해 한 번에 붙여 넣으세요

# 재고 알림 도구 (샌드박스)

사내 교육 실습용 예제 프로젝트입니다.

## 실행 방법

    python3 app.py inventory.csv
EOF

cat > app.py << 'EOF'
import csv
import sys

from utils.formatter import build_alert

THRESHOLD = 10


def load_items(path):
    with open(path, newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))


def main():
    if len(sys.argv) < 2:
        print("usage: python3 app.py <csv path>")
        return
    items = load_items(sys.argv[1])
    low = [i for i in items if int(i["quantity"]) < THRESHOLD]
    for item in low:
        print(build_alert(item))


if __name__ == "__main__":
    main()
EOF

cat > utils/formatter.py << 'EOF'
def build_alert(item):
    return f"[재고 부족] {item['name']} - 현재 {item['quantity']}개"
EOF

cat > inventory.csv << 'EOF'
name,quantity
A4 용지,4

USB 케이블,7
EOF

*.pyc

(출처: code.claude.com/docs/en/troubleshoot-install, 2026-08-26 확인)
설치 중 syntax error near unexpected token '<' 또는 403 오류 설치 스크립트를 정상적으로 내려받지 못함 공식 설치 문제 해결 문서에서 오류 메시지에 맞는 해결책과 대체 설치 방법을 확인합니다. (출처: code.claude.com/docs/en/troubleshoot-install, 2026-08-26 확인)
The token '&&' is not a valid statement separator CMD용 명령을 PowerShell에서 실행함 PowerShell용 명령(irm ...)으로 바꿔 실행합니다. 반대로 'irm' is not recognized가 나오면 CMD이므로 CMD용 명령을 씁니다.
