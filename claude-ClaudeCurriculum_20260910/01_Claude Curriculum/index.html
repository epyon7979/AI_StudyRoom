1. 학습 순서와 트랙

학습은 제품별로 초급 → 중급 → 상급 순서로 진행합니다. 트랙은 주제의 어려움이 아니라 제품을 다루는 방식으로 나눕니다.

트랙코드한 줄 정의전제 지식
초급 basic 기본 설정(default) 그대로 기본 기능을 사용할 수 있다. 설정 변경은 원칙적으로 다루지 않는다. 없음
중급 custom 본인 계정·본인 작업 범위에서 설정과 확장 기능을 커스터마이즈해 개인 워크플로에 맞춘다. 같은 제품 초급 수료
상급 advanced 팀·조직 단위로 표준화·자동화·확산한다. 다른 사람에게 영향을 주거나 관리자 권한·자동 실행이 필요한 범위를 다룬다. 같은 제품 중급 수료
트랙 판정 기준 (경계가 애매할 때)
  • 설정을 바꾸지 않고 되는가 → 초급
  • 본인 계정·본인 작업 범위에서 설정을 바꾸는가 → 중급
  • 다른 사람에게 영향을 주거나, 관리자 권한·자동 실행이 필요한가 → 상급

같은 기능이 여러 트랙에 나타날 수 있습니다. 이때는 트랙별로 다루는 깊이를 나누고, 중복 설명은 상위 트랙 모듈에서 하위 모듈로 링크합니다.

5. 문서 작성 규칙

5-1. 코스 상태

상태의미
미착수모듈 분할안이 아직 없다.
분할 확정모듈 개수·제목·범위가 확정되어 이 문서에 반영되었다.
작성 중확정된 모듈 중 일부가 작성되었다.
완료확정된 모듈이 모두 작성되었다.

5-2. 채번 규칙

  • 모듈 번호 NN은 코스 내 순번으로 01부터 부여합니다.
  • 한 번 부여한 번호와 파일명은 이후에 바꾸지 않습니다. 링크가 깨지기 때문입니다.
  • 중간에 모듈을 삽입해야 하면 번호를 다시 매기지 않고 해당 코스의 다음 번호를 부여합니다. 학습 순서는 이 문서의 나열 순서로만 조정합니다.
  • 모듈 파일의 이전/다음 링크는 이 문서의 나열 순서를 기준으로 하며, 모듈 삽입 시 인접한 2개 파일의 링크만 수정합니다.

5-3. 파일명 규칙

파일명 형식
{product}_{track}_{NN}_{topic}.html

product : claude | cowork | code | design
track   : basic | custom | advanced
NN      : 코스 내 순번 (01부터)
topic   : 영문 소문자와 하이픈

고정 파일은 index.html(로드맵)과 glossary.html(용어집) 2개입니다.

5-4. 모듈 분할 기준

아래 중 하나라도 넘으면 모듈을 분할합니다.

  • 학습 목표가 3개를 넘는다
  • 단계별 실습의 단계가 15개를 넘는다
  • 학습자 실습 예상 소요 시간이 60분을 넘는다
  • 하나의 모듈 안에 서로 독립적인 결과물이 2개 이상 생긴다
분할하지 않는 기준

1개 모듈은 반드시 하나의 완결된 결과물을 만들어야 합니다. 결과물이 나오지 않는 지점에서 자르지 않습니다.

5-5. 모듈 문서 표준 구조

모든 모듈은 아래 순서를 따릅니다.

  1. 모듈 정보 — 제품 / 트랙 / 코스 내 번호·제목 / 예상 소요 시간 / 확인 기준일 / 기준 요금제 / 기준 버전
  2. 학습 목표 — 최대 3개, "~을 할 수 있다" 형태
  3. 사전 준비 — 필요 플랜, 설치 여부, 사전 지식, 예상 사용량
  4. 핵심 개념 — 두괄식
  5. 단계별 실습 — 단계마다 캡처 지시서 또는 코드·프롬프트 예시 최소 1개
  6. 예제 코드·예제 프롬프트 — 그대로 복사해 실행 가능한 완전한 형태
  7. 트러블슈팅 — 자주 발생하는 오류 2~5개와 해결법
  8. 확인 체크리스트 — 3~5문항
  9. 필요 캡처 목록 — 캡처 지시서를 번호순으로 정리
  10. 참고 자료 — 문서명, URL 또는 첨부 파일명, 확인 날짜
  11. 최종 확인일
