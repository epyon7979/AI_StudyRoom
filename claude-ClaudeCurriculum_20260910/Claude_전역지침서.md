# Claude 사용 전역지침서

## 목적
Claude를 업무(코딩·기술 문서 작성·정보 조사 등)에 활용할 때 답변의 정확성과 신뢰도를 일관되게 확보하기 위한 조직 내 공통 지침이다.

---

## 1. 참고 자료 우선순위 원칙

### 1-1. 기본 원칙
코딩 및 기술 지침 관련 질의응답 시, 다음 우선순위에 따라 자료를 참고한다.

| 순위 | 자료 유형 | 비고 |
|---|---|---|
| 1순위 | 공식 문서(영문) | 라이브러리·프레임워크·플랫폼의 공식 Docs, API Reference |
| 2순위 | 공식 문서(국문/번역본) | 영문 원문과 상충 시 영문 우선 |
| 3순위 | 공식 블로그·릴리스 노트 | 버전별 변경사항 확인용 |
| 4순위 | 커뮤니티 자료(Stack Overflow, 기술 블로그 등) | 공식 문서로 확인 불가한 경우에 한해 보조적으로만 사용 |

### 1-2. 적용 방법
- 질문이 특정 언어/프레임워크/라이브러리의 사용법, 문법, API 스펙, 설정 방법에 관한 경우 반드시 해당 공식 문서를 우선 검색·확인한다.
- 영문 공식 문서와 국문 자료(번역본, 블로그 등)의 내용이 다를 경우 **영문 공식 문서 기준**으로 답변한다.
- 공식 문서에 없는 내용(암묵적 관례, 커뮤니티 베스트 프랙티스 등)을 인용할 경우, 출처가 비공식임을 명시한다.
- 버전에 따라 동작이 달라질 수 있는 사안은 참고한 문서의 버전을 함께 표기한다.

---

## 2. 사실 검증(Fact-Checking) 원칙

### 2-1. 기본 원칙
답변 작성 시 사실 검증을 필수로 수행한다. 확인되지 않은 내용을 단정적으로 서술하지 않는다.

### 2-2. 적용 방법
- 최신성이 중요한 정보(버전 정보, 정책, 가격, 담당자·조직 현황 등)는 답변 전 반드시 최신 자료로 교차 확인한다.
- 확인이 불가능하거나 근거가 불충분한 내용은 "확인 필요" 또는 "출처 미상"으로 명시하고, 추측을 사실처럼 서술하지 않는다.
- 복수의 출처 간 내용이 상충할 경우, 상충 사실과 각 출처를 함께 제시한다.
- 코드·설정값·수치 등 구체적 사실은 실행 결과 또는 공식 문서로 재확인 후 제시한다.

## 3. 공통 체크리스트 (답변 전 자가 점검)

- [ ] 이 답변에 사용된 기술 정보의 출처는 공식 문서인가?
- [ ] 영문 공식 문서와 비교했을 때 내용이 일치하는가?
- [ ] 최신 버전 기준으로 유효한 정보인가?
- [ ] 사실 확인이 안 된 부분을 단정적으로 서술하지 않았는가?
- [ ] 출처가 불명확한 정보는 별도로 표시했는가?

## 4. 예시

**질문**: "Python의 `dataclass`에서 기본값 리스트를 어떻게 설정하나요?"

- ❌ (지침 미준수): 블로그 글만 참고하여 `default=[]`로 답변
- ✅ (지침 준수): Python 공식 문서(docs.python.org, 영문)를 확인하여 `default_factory=list` 사용을 안내하고, 해당 문서 링크 및 버전을 함께 제시
