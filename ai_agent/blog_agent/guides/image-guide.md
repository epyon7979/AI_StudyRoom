# 이미지 제작 가이드

> image-maker 에이전트가 읽는 가이드입니다.
> 모든 이미지는 HTML + CSS로 마크업한 뒤, Python으로 Playwright를 실행해서 PNG로 캡처합니다.

---

## 1. 대표 이미지 (썸네일)

### 규격
- 크기: **1080 × 1080px** (1:1 정사각형)
- 배경: 어두운 블루-퍼플 그라데이션 (`#1a1a2e` → `#16213e`, 좌상단에서 우하단 방향)

### 텍스트
- **메인 텍스트**: 글 제목. 큰 글씨, 흰색(`#ffffff`).
- **보조 텍스트**: 카테고리 또는 부제. 작은 글씨, 연한 회색(`#a0a0b0`).
- 모든 텍스트는 가로/세로 중앙 정렬.

### 폰트
- Pretendard 우선. 없으면 시스템 기본 한글 폰트(`Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif` 순 fallback).

### 액센트 요소
- 우측 하단 또는 좌상단에 작은 액센트를 하나 배치한다.
- 도형(원, 사각형), 코드 심볼(`</>`, `{ }`, `#`), 또는 단순한 아이콘 형태.
- 글의 주제나 카테고리와 어울리는 심볼을 선택한다.

## 2. 본문 삽입 이미지

글 내용에 맞는 유형을 아래 네 가지 중에서 선택한다.

### 유형 1 — 비교 표
**사용 시점**: 두 개 이상의 제품, 방법, 옵션을 나란히 비교할 때.

구성:
- 좌우 또는 상하로 항목을 나열한다.
- 각 항목의 차이가 한눈에 보이도록 핵심 속성만 표시한다.
- 헤더 행에 비교 기준, 각 열에 대상 항목.

### 유형 2 — 단계별 다이어그램
**사용 시점**: 절차나 순서, 흐름을 보여줄 때.

구성:
- 단계를 번호(1, 2, 3…)와 함께 순서대로 나열한다.
- 단계 사이는 화살표(`→`)로 연결한다.
- 각 단계 텍스트는 한 줄 이내로 짧게 유지한다.

### 유형 3 — 핵심 포인트 카드
**사용 시점**: 3~5개의 요점을 정리할 때.

구성:
- 카드 형태로 요점을 나열한다 (3~5개).
- 각 카드에 번호 또는 짧은 제목 + 한 줄 설명.
- 카드끼리 일정한 간격으로 배치.

### 유형 4 — 인용/강조 박스
**사용 시점**: 중요한 한 마디, 핵심 문장을 강조할 때.

구성:
- 강조할 문장을 큰 글씨로 중앙에 배치한다.
- 따옴표 기호(`"`) 또는 강조 구분선으로 시각적으로 구분한다.
- 출처나 맥락이 있으면 작은 글씨로 하단에 표시한다.

## 3. 공통 제작 규칙

### 디자인
- 배경 톤은 대표 이미지와 통일감 있게 어두운 계열로 유지한다.
- 텍스트는 최대한 짧게. 이미지는 보조 수단이지 본문 대체물이 아니다.
- 코드 블록 스타일(모노스페이스 폰트, 어두운 배경, 테두리)을 디자인 요소로 활용할 수 있다.

### 제작 방식
- HTML + CSS로 마크업한다.
- Python으로 Playwright를 실행해서 PNG로 캡처한다.
- 캡처 시 뷰포트 크기는 이미지 규격과 정확히 일치시킨다.
- 저장 경로: `output/[주제]/images/[파일명].png`

### 파일명 규칙
- 대표 이미지: `thumbnail.png`
- 본문 삽입 이미지: 순서와 내용을 반영한 이름. 예: `01-workflow-diagram.png`, `02-feature-cards.png`
