# 블로그 문체 스타일 가이드

> 이 문서는 세 편의 블로그 글(전자제품 리뷰, 여행기, AI 기술 에세이)을 분석해 도출한 필자 고유의 문체 패턴입니다.
> 이 가이드만으로도 동일한 톤과 리듬으로 글을 작성할 수 있도록 구성했습니다.

> ※ 제목 끝에 **(보완)**이 붙은 섹션(3, 7, 8)은 원본 캡처에 없어서, 나머지 섹션과 체크리스트를 근거로 정리한 내용입니다.

---

## 1. 말투 기본 톤

### 경어체 + 친근한 거리감

- 전반적으로 `-습니다` / `-ㄴ데요` 형식의 존댓말을 사용하되, 딱딱하지 않음
- 독자에게 말을 거는 듯한 느낌. 강의가 아니라 **옆에 앉아 이야기하는 톤**
- 주관적 경험을 솔직하게 드러냄 ("솔직히 말씀드리면", "저는 ~합니다")
- 과도한 격식이나 전문가 포즈 없음. 자기 한계와 단점도 먼저 꺼냄

### 피해야 할 톤

- "~라고 할 수 있겠습니다" 같은 논문투
- "여러분!" 같은 과잉 친밀감
- 중립적인 제3자 서술 ("~하는 것으로 알려져 있다")

## 2. 문장 끝맺음 패턴

자주 쓰는 어미 유형:

| 어미 유형 | 예시 | 용도 |
| --- | --- | --- |
| `-ㄴ데요` | "이 차이는 스펙표에 나오지 않습니다. 직접 써봐야 아는 부분이었는데요." | 부연 설명, 여운 남기기 |
| `-습니다` | "결론부터 말씀드리면 — 확실히 다릅니다." | 단호한 결론, 짧고 명확한 주장 |
| `-했습니다` | "저는 30분 동안 그냥 거기 서 있었습니다." | 과거 경험 서술 |

---

## 3. 문장 구조와 리듬 (보완)

- **긴 문장 뒤에는 짧은 문장**을 붙여 리듬을 끊는다. 설명은 길게 풀고, 주장은 짧게 끊는다.
  - 예: "결론부터 말씀드리면 — 확실히 다릅니다." / "아무도 없었습니다."
- **단락은 4문장을 넘기지 않는다.**
- 결론이나 반전은 대시(`—`)로 이어서 강조한다.
- 접속은 구어체로 한다. 문어적 접속사는 쓰지 않는다. (4장 참고)

---

## 4. 자주 쓰는 표현과 어휘

### 선행 솔직함 (먼저 약점을 고백하는 패턴)

> "솔직히 말씀드리면, 저도 처음 ChatGPT를 써봤을 때 그렇게까지 감동받지 않았습니다."
> "가격이 비쌉니다. 40만원대 초반으로 헤드폰치고 부담스러운 것은 사실인데요."

→ 독자의 예상 반론을 **필자가 먼저 꺼냄**. 방어적이지 않고 오히려 신뢰감을 만드는 장치.

### 결론 선제시 + 이유 후술

> "결론부터 말씀드리면 — 확실히 다릅니다."
> "아무도 없었습니다." [→ 이후에 경험 서술]

→ 결론을 먼저 주고, 이유와 경험은 뒤에 풀어냄.

### 구어적 접속 표현

- "그래서", "그런데", "하지만", "물론 ~ 하지만"
- "그리고 이 속도 차이는…"
- 문어적 접속사(따라서, 그러므로) 거의 사용 안 함

### 감각적 묘사 어휘

- 추상 개념을 신체 감각으로 표현: "소리가 '잘립니다'", "배경 자체가 사라지는 느낌", "머릿속이 잠깐 비워지는 느낌"
- 큰따옴표 대신 **작은따옴표**로 뉘앙스 강조: `'줄여주는'`, `'잘립니다'`, `'털털'`

### 반복 피하기 + 재진술

동일한 내용을 다른 표현으로 한 번 더 확인시켜줌:

> "매일 출퇴근하고, 카페에서 일하고, 운동하면서 쓰는 분이라면 충분히 값어치를 합니다."
> (= 앞서 말한 '가격이 비쌈'을 다른 각도에서 재해석)

## 5. 도입부 패턴

**공식: 개인 전제 표명 → 기대 어긋뜨리기 → 본론 진입**

```
1. "저는 ~을 별로 좋아하지 않습니다" / "솔직히 저도 ~"
   → 필자의 입장과 성향을 먼저 밝힘

2. "그래서 ~을 해봤습니다" / "그런데 달라졌습니다"
   → 변화나 계기를 제시

3. 본론 시작
```

**예시:**

> "저는 언박싱 영상이나 '스펙 비교표' 스타일의 리뷰를 별로 좋아하지 않습니다."
> → "그래서 이 리뷰는 6개월간 매일 쓴 사람의 이야기입니다."

> "저는 여행 계획을 잘 안 세우는 편입니다."
> → "그래서 이번 교토는 처음부터 달리 가보기로 했습니다."

> "솔직히 말씀드리면, 저도 ChatGPT를 써봤을 때 그렇게까지 감동받지 않았습니다."
> → "그런데 1년이 지나고, 2년이 지나면서 뭔가 달라지기 시작했습니다."

## 6. 마무리 패턴

**공식: 한 줄 요약 → 독자에게 행동/관점 제안 → 여운**

```
1. 핵심 메시지를 한 문장으로 압축 (때로 따옴표로 강조)
2. "~분이라면", "~해보시길 권합니다" 형식의 독자 제안
3. 이유를 짧게 덧붙이며 마무리 (여운 남기는 마지막 문장)
```

**예시:**

> "딱 한 줄로 정리하면 이것입니다. / '단점을 알고 사면 실망 없는 제품.'"

> "한 번 직접 매장에서 써보시길 권해 드립니다. / 노이즈 캔슬링은 글로 읽는 것과 귀로 듣는 것이 완전히 다른 경험이니까요."

> "다음에 또 가고 싶은 도시가 있냐고 물으신다면, 주저 없이 교토라고 말할 것입니다. / 아직 못 찾은 골목이 거기 남아 있으니까요."

**마지막 문장 특징:** 이유를 `~니까요`로 끝냄 → 단정짓지 않고 독자가 공감할 여지를 남김.

## 7. 글 유형별 적용 (보완)

위 패턴을 글 유형에 맞게 쓰는 방법입니다. 예시 문장은 이 문서의 예시에서 가져왔습니다.

| 유형 | 도입 | 중심 | 마무리 |
| --- | --- | --- | --- |
| 전자제품 리뷰 | 스펙표 위주 리뷰를 싫어한다고 밝히고, 직접 오래 쓴 사람의 이야기임을 제시 | 가격 같은 약점을 먼저 인정하고, 소리·착용감 같은 것은 감각적 표현으로 풀기 | "직접 써보시길 권합니다" + `~니까요` |
| 여행기 | 계획을 잘 안 세우는 편이라는 전제 → 이번엔 달랐다는 반전 | `-했습니다`로 시간 흐름에 따라 경험 서술 | 재방문 의사 + `~니까요` |
| AI 기술 에세이 | 처음엔 감동받지 않았다는 고백 → 시간이 지나며 달라졌다는 반전 | 변화의 계기와 경험을 구체적으로 | 한 줄 요약 + 독자에게 관점 제안 |

### 사실·경험 관련 주의

- 이 문체는 필자의 **직접 경험**을 중심에 둡니다. 경험은 필자가 제공한 것만 씁니다. 지어내지 않습니다.
- 경험 자료가 없는 자리에는 경험담 대신 `[경험 보강 필요]`라고 표시하고 넘어갑니다.
- 수치와 사실은 research.md에 있는 것만 씁니다. 출처를 밝히는 문장도 구어체로 씁니다.

## 8. 바꿔 쓰기 예시 (보완)

1장의 "피해야 할 톤"과 4장의 접속 표현 규칙을 문장으로 바꾼 것입니다.

| 피하기 | 이렇게 쓰기 |
| --- | --- |
| "~라고 할 수 있겠습니다" | "~입니다" 또는 "저는 ~라고 느꼈습니다" |
| "여러분, 꼭 써보세요!" | "써보시길 권해 드립니다" |
| "~하는 것으로 알려져 있다" | 경험이 있으면 "직접 써보니 ~했습니다", 없으면 출처를 밝히며 "~라고 설명합니다" |
| "따라서", "그러므로" | "그래서" |
| 큰따옴표로 강조 ("잘린다") | 작은따옴표로 강조 ('잘립니다') |

## 9. 이 문체로 쓸 때 체크리스트

- [ ] 도입부에서 필자의 입장/성향을 먼저 밝혔는가?
- [ ] 결론을 앞에 두고 이유를 뒤에 풀었는가?
- [ ] 긴 문장 뒤에 짧은 문장으로 리듬을 끊었는가?
- [ ] 단락이 4문장을 넘기지 않는가?
- [ ] 추상적 설명을 감각적 표현으로 바꿨는가?
- [ ] 독자의 예상 반응을 먼저 꺼냈는가?
- [ ] 마무리가 `~니까요` 또는 여운 있는 한 문장으로 끝나는가?
- [ ] 작은따옴표를 활용해 뉘앙스를 살렸는가?
- [ ] 논문투 접속사(따라서, 그러므로)를 쓰지 않았는가?
