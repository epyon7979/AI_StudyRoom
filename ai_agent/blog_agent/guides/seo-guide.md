## 1. 제목 작성 규칙

### 글자 수
| 출처 | 권장 |
| --- | --- |
| 체류시간 중심 가이드 (sigmine, 2026.5) | 25자 이내 |
| 체크리스트 (locaposting) | 30~40자 이내. 모바일 검색 결과에서 약 35자까지 표시되고 그 뒤는 잘림 |

- 🟡 **정리:** 모바일 기준으로 핵심 내용이 앞쪽 30~35자 안에 들어오도록 쓰면 어느 기준에도 걸리지 않습니다.
- 네이버 블로그 에디터 자체의 제목 글자 수 제한은 느슨해서(100자 안팎 권장이라는 자료도 있음) 제한보다는 "잘림"이 기준입니다.

### 키워드 위치
- 🟡 핵심 키워드는 **제목 앞쪽에 1회**, 문장 안에서 자연스럽게 배치합니다. (예: "네이버 블로그 상위노출 실전 전략")
- 🟡 숫자나 구체적 표현(연도, 개수, 지역명)을 넣으면 클릭 이유가 생깁니다.
- 🟡 대형 키워드보다 자동완성·스마트블록에 나오는 **세부 의도(롱테일) 키워드**가 경쟁이 덜합니다. 연관검색어가 종료되었으므로 자동완성과 스마트블록 제안어를 활용하세요.
- 🟢 제목은 본문 내용과 일치해야 합니다. 본문과 관련 없는 인기 검색어를 붙이는 것은 품질 평가에서 불이익을 받는 방향입니다.

### 피해야 할 단어·패턴
- 🔴 네이버가 공개한 "금지 단어 목록"은 확인하지 못했습니다. 특정 단어가 곧바로 불이익이라는 주장은 근거가 없습니다.
- 🟡 대신 다음 패턴은 스팸·어뷰징 신호로 자주 언급됩니다.
  - 같은 키워드를 제목에 반복하거나 키워드만 나열
  - 본문과 무관한 인기·이슈 키워드 끼워넣기
  - 과장·낚시성 표현, 특수문자 남발
  - 광고·홍보 의도가 제목에서 바로 드러나는 문구

## 2. 본문 구조

### 기본 구조
- 🟡 **두괄식(결론 먼저):** 첫 문단에 핵심 답을 제시합니다. AI 브리핑이 인용하기 좋은 구조이기도 합니다.
- 🟡 **소제목으로 구분:** 실제 검색어처럼 질문형 소제목이 유리하다는 의견이 많습니다.
- 🟡 **표·리스트·수치:** "좋다"보다 "전년 대비 20% 상승"처럼 구체적인 수치가 있는 문장이 인용에 유리하다는 분석이 있습니다.
- 🟡 **FAQ 3~5개:** 글 끝에 Q&A를 두면 AI 요약에 쓰이기 쉽다는 에이전시 주장이 있습니다. (공식 확인 없음)
- 🟡 **체류시간:** 평균 2분 30초~3분 이상이 상위 유지에 필요하다는 주장이 있으나 단일 출처입니다.

### 도입-본론-결론 비율
- 🔴 검증된 공식 비율은 없습니다.
- 💡 **작성용 틀(제안):** 도입 10~15% (문제 제기 + 결론 요약) / 본론 70~80% (소제목별 근거·경험·사진) / 결론 10~15% (요약 + 행동 제안 + FAQ)

### 본문 길이
| 출처 | 권장 |
| --- | --- |
| 일반 가이드 | 1,000자 이상 |
| 체크리스트 | 1,500자 이상 (상위노출 글 평균 2,000~3,000자라고 주장) |
| 에이전시 | 1,500~2,000자가 최적 |

- 🟡 **정리:** 1,500자 이상을 하한으로 잡고, 정보량이 충분하다면 2,000~3,000자까지 확장합니다. 길이를 채우기 위한 군더더기는 오히려 체류시간을 떨어뜨립니다.

### 소제목 활용
- 소제목은 "무엇을 다루는지"가 보이게 쓰고, 핵심 키워드 또는 동의어를 일부 소제목에 자연스럽게 포함합니다.
- 줄글만 길게 쓰기보다 핵심은 표나 목록으로 정리합니다.

## 3. 키워드 밀도와 배치

| 출처 | 권장 |
| --- | --- |
| 에이전시 (AMPM) | 키워드 밀도 약 2~3% |
| 체크리스트 (locaposting) | 본문에 3~5회 자연스럽게 + 동의어·관련 키워드 병행 |
| 2026 저품질 분석글 (tilnote) | 밀도 수치보다 검색 의도 부합과 문맥 속 자연스러움이 중요 |

- 🟡 **정리:** 밀도 수치에 집착하지 말고, 핵심 키워드는 **제목 1회 + 첫 문단 + 일부 소제목 + 마무리**에 자연스럽게 배치합니다. 2,000자 기준으로 보면 3~5회 안팎이 됩니다.
- 🟡 동의어, 연관어, 질문형 문장을 섞어 "한 단어만 반복"하지 않습니다.
- 🟢 의도적 키워드 반복은 어뷰징 유형에 해당합니다 (7장 참고).
- 🟡 직접 경험과 전문성이 드러나는 글은 키워드를 덜 넣어도 의도에 부합하는 것으로 평가된다는 분석이 많습니다.

## 4. 이미지

### 몇 장이 적절한가
| 출처 | 권장 |
| --- | --- |
| 에이전시 가이드 | 직접 촬영 3장 이상 |
| 체크리스트 | 원본 이미지 5장 이상, 영상 1개 이상 |
| sigmine (2026.5) | 직접 촬영 고화질 6~13장 + 15초 이상 동영상(모먼트) |

- 🟡 **정리:** 3장은 최소선, 정보성 글은 5장 이상을 권장하는 의견이 다수입니다. 장수를 늘리는 것보다 **원본 사진**이라는 점이 더 중요합니다.
- 🟡 스톡 이미지·도용 이미지는 불리하고, 사진만 많고 글이 빈약한 포스트는 성과가 낮다는 지적이 일관됩니다.
- 🟡 이미지에 글자를 넣어 정보를 전달한다면(카드뉴스 등) 같은 내용을 본문 텍스트로도 적어야 합니다.

### alt 텍스트
- 🟢 네이버 서치어드바이저는 텍스트 중심으로 구성하고 이미지에는 설명(alt)을 달 것을 권장합니다. (웹사이트 대상 안내)
- 🟡 이미지가 무엇인지 짧고 구체적으로 설명하고, 지나치게 긴 설명이나 키워드 나열은 스팸으로 오인될 수 있습니다.
- 🟡 이미지 파일명에 키워드를 넣는 것은 효과가 작은(★ 수준) 보조 항목으로 분류됩니다.
- 네이버 블로그 에디터에서 대체 텍스트를 입력하는 기능과 위치는 에디터 버전에 따라 다를 수 있으니 직접 확인하세요.

### 대표 이미지 규격
- 🔴 네이버의 공식 규격 문서는 확인하지 못했습니다. 아래는 이미지 도구 사이트의 권장값입니다.

| 용도 | 권장 크기 | 비율 |
| --- | --- | --- |
| 게시글 썸네일 | 1300 x 885 px | 약 3:2 |
| 모바일 앱 커버 | 1080 x 1300 px | 약 5:6 |
| 카드뉴스 | 1300 x 1300 px | 1:1 |
| 가로형 대표 이미지 | 1200 x 675 px | 16:9 |

- 💡 PC 스킨과 모바일 앱의 노출 방식이 다르므로 핵심 문구와 피사체는 중앙에 배치하세요. 대표 이미지는 첫 번째 사진이나 지정 썸네일이 쓰이므로 원본 사진 중 가장 선명한 것을 고르세요.

## 5. 해시태그 활용법

- 🔴 네이버 블로그 태그가 순위에 미치는 영향이나 권장 개수에 대한 공식·검증 자료는 찾지 못했습니다. 아래는 업계 관행과 제안입니다.
- 🟡 포스트 태그를 10개 안팎으로 채우는 운영자가 많고, 모바일 검색(맛집·장소 등)에서 도움이 된다는 의견이 있습니다. 반면 중요도는 크지 않다는 의견도 있습니다.
- 💡 **제안:** 본문 주제와 직접 관련된 핵심 키워드 + 세부 키워드 5~10개. 본문과 무관한 인기 태그를 붙이지 않습니다. 같은 단어를 변형해 대량으로 도배하지 않습니다.
- 인스타그램의 "해시태그 5개" 기준은 인스타그램 정책이므로 네이버 블로그에 그대로 적용하지 않습니다.

## 6. C-Rank, D.I.A.가 좋아하는 패턴

### C-Rank (블로그·출처의 신뢰도)
| 패턴 | 내용 | 근거 |
| --- | --- | --- |
| 주제 일관성 | 한 분야를 꾸준히 다룸. 여러 주제를 섞으면 전문성 판단이 어려워짐 | 🟢 다수 일치 |
| 꾸준한 발행 | 발행 "횟수"보다 일관된 주제의 꾸준한 발행. 주 2~3회 고품질 발행이 흔한 권장 | 🟡 |
| 전문성·권위 | 프로필에 전문성·경력 명시, 공식 자료(통계·법령·제조사) 링크 1~2개 | 🟡 |
| 출처 신뢰도 | 2026년에는 AI가 출처 신뢰도를 판별해 공식 사이트·전문기관 채널에 가산점을 준다는 해석 | 🟡 |

### D.I.A. / D.I.A.+ (문서 품질·검색 의도)
| 패턴 | 내용 | 근거 |
| --- | --- | --- |
| 직접 경험 | 본인이 찍은 사진, 독창적 의견, 문제 해결 과정 | 🟢 다수 일치 |
| 검색 의도 부합 | 검색자가 원하는 답을 글 앞부분에서 제시 | 🟢 |
| 정보성·구조 | 소제목, 표, 목록, 수치 데이터 | 🟡 |
| 가독성·체류 | 불필요한 서술 삭제, 정보 밀도 유지 | 🟡 |
| 정보성 80% : 홍보성 20% | 홍보 비중을 낮게 유지하라는 sigmine 권장 | 🟡 단일 출처 |
| 사용자 반응 | 자연스러운 댓글·공감·재방문 (인위적 작업은 역효과) | 🟡 |

### AI 브리핑에 인용되기 좋은 글 (2026년 신규)
- 🟡 결론을 먼저 쓰고, H 소제목과 목록·표로 구조화하고, 구체적인 수치를 넣습니다.
- 🟡 AI가 대량 생성한 정보 나열형 글은 뒤로 밀린다는 분석이 많으므로, AI를 초안 도구로 쓰더라도 직접 경험과 사진을 반드시 반영합니다.

### 단일 "블로그 지수"는 공식 개념이 아닙니다
- 🔴 "블로그 지수", "최적화 블로그", "저품질 블로그" 같은 용어는 네이버의 공식 용어가 아니고, 운영자들이 체감 상태를 부르는 말이라는 설명이 반복됩니다. 노출은 단일 점수가 아니라 수집·색인·품질·스팸 필터 등 여러 요소의 결과로 봐야 합니다.

## 7. 어뷰징으로 판정되는 것들 (피해야 할 것)

네이버는 스팸·어뷰징 문서의 기준으로 문서 복사, 유사·의도적 키워드 반복 등을 들어왔고, 2025년 3월 UGC 문서 노출 시스템 고도화 공지 이후 AI로 대량 생성한 저품질 글과 경험 없는 광고성 도배 글에 대한 판별을 강화한다고 알려져 있습니다. (공지 내용을 인용한 2차 자료 기준)

| 유형 | 내용 | 근거 |
| --- | --- | --- |
| 복사·유사 문서 | 복사 붙여넣기, 거의 같은 글 반복 발행 | 🟢 |
| 키워드 스터핑 | 같은 키워드의 비정상적 반복, 키워드 나열 | 🟢 |
| 저품질 대량 발행 | AI·템플릿으로 짧은 글을 대량 발행 | 🟡 |
| 광고성 링크 남발 | 홍보성 링크·배너를 불필요하게 삽입, 제휴 링크 과다 | 🟡 |
| 자동화·인위적 조작 | 클릭 수·공감·댓글을 도구로 늘리는 행위, 블로그 매매·공장식 운영 | 🟡 |
| 숨김 텍스트 | 사용자에게 보이지 않게 키워드를 숨기는 행위 (웹 스팸 일반 기준) | 🟢 |
| 이미지만 많고 글은 빈약 | 실질 텍스트 없는 사진 위주 글 | 🟡 |
| 본문과 무관한 제목·키워드 | 인기 검색어를 끼워넣는 낚시성 제목 | 🟡 |

**근거 없이 떠도는 주장 (공식 확인 못함)**
- 하루 몇 개 이상 발행하면 어뷰징 → 네이버가 경고하는 것은 발행 개수가 아니라 조작 행위라는 설명이 있습니다. 다만 저품질 글의 대량 발행은 위험합니다.
- 특정 시간대에 발행해야 유리 → 공식 근거 없음
- 글을 수정하면 불이익 → 공식 근거 없음

## 8. 발행 전 체크리스트

**제목**
- [ ] 핵심 키워드가 앞쪽에 1회, 앞 30~35자 안에 핵심이 보인다
- [ ] 본문 내용과 일치하고 낚시·키워드 나열이 아니다

**본문**
- [ ] 첫 문단에 결론 또는 핵심 답이 있다
- [ ] 소제목으로 구분하고 표·목록을 적절히 썼다
- [ ] 1,500자 이상이며 군더더기가 없다
- [ ] 직접 겪은 경험·수치·근거가 들어 있다
- [ ] 공식 자료 링크는 1~2개로 제한했다

**키워드**
- [ ] 제목·첫 문단·소제목·마무리에 자연스럽게 배치했다
- [ ] 동의어·연관어를 섞었고 같은 단어를 억지로 반복하지 않았다

**이미지**
- [ ] 직접 찍은 사진 3장 이상 (정보성 글은 5장 이상 권장)
- [ ] 대표 이미지는 선명한 원본이고 핵심이 중앙에 있다
- [ ] 이미지 속 글자 정보는 본문에도 텍스트로 적었다

**운영**
- [ ] 블로그 주제가 일관되고 프로필에 전문성이 드러난다
- [ ] 복사·유사 글이 없고 광고성 링크가 과하지 않다
- [ ] 발행 후 필요하면 검색 반영 여부를 확인했다 (따옴표 완전일치 검색으로 색인 누락과 순위 밀림을 구분)
